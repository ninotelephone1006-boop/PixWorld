# PixWorld

Prototype de jeu de plateforme 2D en HTML Canvas.

Ouvre `index.html` dans un navigateur pour jouer.

## Commandes

- `Q` : aller à gauche
- `D` : aller à droite
- `Espace` : sauter

Les flèches gauche/droite fonctionnent aussi. Cette première version est une base locale ; le multijoueur réseau pourra être ajouté ensuite.
